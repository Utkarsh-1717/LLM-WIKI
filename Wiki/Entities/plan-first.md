# Plan-First Skill

The [[plan-first]] skill mandates that agents construct a detailed, formal plan document inside `LLM-WIKI/Plans/` before executing complex sequences of actions. This ensures that users retain visibility into proposed changes and can interrupt if the agent misunderstands the objective.
