## Key Lessons

1. **Session-open bars must be nulled** — not just filtering to market hours. The 09:15 bar's return is still an overnight return.
2. **Two-pass alignment over strict inner-join** — strict inner-join collapsed 44k → 17k bars. Two-pass retained 39k bars.
3. **`except Exception` not `except ImportError`** — GPU libraries can fail with AttributeError, MemoryError, etc.
4. **Kaggle slug ≠ kernel-metadata.json id** — always parse real slug from push output URL.
5. **nbformat 4.5+ requires cell `id` fields** — missing IDs cause papermill cell ordering failures.
