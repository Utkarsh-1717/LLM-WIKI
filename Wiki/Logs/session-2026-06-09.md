# Session Log — 2026-06-09 to 2026-06-10

## Session Summary

This session was the most comprehensive validation run of the pairs trading strategy, expanding from 5 pairs to all 500 Pearson-screened pairs and discovering a fundamental methodological error in the Z-score window.

---

## Key Discoveries

### 1. Z-Score Window Bug (Critical Fix)
The original implementation used `ZSCORE_WINDOW = 375` (1 trading day). True pair half-lives are 642–3,400 minutes (2–9 days). A 1-day window re-centers the mean faster than pairs can revert, causing 95%+ of trades to exit prematurely and bleed capital to friction. Fixed to `ZSCORE_WINDOW = 7500` (20 days).

### 2. 500-Pair Full Backtest Results
After the fix, the Kalman Worst-Case method identified **168 profitable pairs** with **+₹6,29,847 total positive PnL** (₹70.29/trade). The overall portfolio remains net-negative because ~332 non-cointegrated pairs drag it down.

### 3. OLS vs Kalman — Fundamental Difference
- Kalman is dynamic: beta updates every minute. More trades, smaller profits per trade. Cannot be ADF-tested.
- EOD OLS is stationary intraday: very few trades, very high PnL per trade. Daily beta jumps break the ADF test.
- Continuous Rolling OLS: beta updates every minute using vectorized math. Smooth spread. Valid ADF test.

### 4. Cointegration Filter — The Key Insight
Running Engle-Granger ADF on the Continuous OLS spread revealed that **358 of 500 pairs** are truly cointegrated. Applying this filter to the portfolio flips it from −₹4,09,911 to **+₹54,937** profit.
