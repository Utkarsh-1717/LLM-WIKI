# Naming Conventions

- **Filenames**: Use kebab-case for all markdown files (e.g., `llm-wiki.md`, `raw-vs-wiki.md`). Do not use spaces or capital letters in filenames.
- **Titles**: Use Title Case inside the `# Heading 1` of the note.
- **Folders**: Core directories use PascalCase (`Raw/Sources/`, `Wiki/Concepts/`).
- **Tags**: Use lowercase for frontmatter tags (`topic`, `concept`).
